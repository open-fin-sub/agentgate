## 第一批：A 结构化输入与已定范围变更

采用现有 Vue、Element Plus、tokens 和 API，没有另建前端。新增共享 MessageInput、KeyValueEditor、JsonValueInput、PayloadInput、RuleBuilder、SchemaBuilder、FormSection、JsonFallback、ValueView、ExpectationSummary；MetadataGroup/TokenUsage 用于用量与完整预期摘要。其他已建立模式组件在后续类别逐步迁移，不以“文件存在”宣称落地。

- 真实用例输入采用消息与变量行；预期完整覆盖现有六类合同。删除将流程/工具/策略压平的有损转换，保存时保留检查编号、名称、顺序和复杂条件。没有增加 API 字段或兼容别名。
- Mock 变量、规则与试评改结构化表单；导入以选文件、字段映射、校验为主，粘贴内容进入高级折叠。
- 证据采用可读值和预期摘要，原始快照只通过 JsonFallback 展开；未采集与零值区分。可选分类、变量、样本范围、执行参数收进共享分区。
- 新评估器目录读取摘要后按精确版本读取配置。复用历史配置时比较实体、版本、内容哈希，避免误用已变化的标准。
- 已定变更 RC-01：移除货币字段/计算/指标/阈值，改输入、输出、总 Token 与耗时。Mock 判定使用平均单例 Token；真实应用只展示实际采集值与范围，未提供整体用量时不伪造。
- 已定变更 RC-02：自动生成入口隐藏，旧链接降级为手工创建；生成源模块留待后续。风险验证手工填写并保留来源。自动生成旧 UI 测试另存任务产物，当前验收换为手工多轮发布 v1、文件导入及旧入口降级。

## G 类：任务文案与状态反馈（本批验证通过）

设计：复用 A 类已建立的 StatusNotice/EmptyState。状态提示保留原条件、错误/警告语义和动作；空状态按页面任务分别给出下一步，不以泛化“无数据”替代。真实请求错误通过 userError 区分权限、失效引用、冲突、输入错误与服务不可用；文件导入保留逐行校验信息。模拟工作区保留统一模拟数据标识，删除分散的架构、路线图说明。
